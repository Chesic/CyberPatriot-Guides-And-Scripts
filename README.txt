CyberPatriot Guides and Scripts
by Lucas Ches

This Folder Contains CyberPatriot Checklists and Scripts to help ease your CyberPatriot experience. 

You can access these scripts by using a git pull request:
git pull https://github.com/Chesic/CyberPatriot.git

Which folder to use:
  Ubuntu or Linux Mint image -> linux_scripts/ubuntu
      sudo bash linux_scripts/ubuntu/cyberPatriot_Script_Ubuntu.sh
      Manual guide: linux_scripts/ubuntu/manual_hardening_reference_Ubuntu.md
  Debian image -> linux_scripts/debian
      sudo bash linux_scripts/debian/cyberPatriot_Script_Debian.sh
      (if sudo isn't set up yet: su -   then   bash linux_scripts/debian/cyberPatriot_Script_Debian.sh)
      Manual guide: linux_scripts/debian/manual_hardening_reference_Debian.md
